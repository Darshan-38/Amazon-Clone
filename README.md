# 🛒 Amazon Clone

A modern Amazon homepage clone built using **HTML** and **CSS**.  
This project recreates the look and feel of Amazon’s landing page with responsive layouts, navigation bars, product sections, hover effects, and footer design.

---

## 🚀 Features

- ✅ Amazon-style navigation bar
- ✅ Search bar with categories
- ✅ Hero banner section
- ✅ Product grid/cards
- ✅ Hover effects
- ✅ Footer section
- ✅ Smooth scroll “Back to Top” button
- ✅ Font Awesome icons
- ✅ Clean UI inspired by Amazon

---

## 🛠️ Technologies Used

- **HTML5**
- **CSS3**
- **Font Awesome**
